# 拜访历史分析 Skill

当用户想复盘某商家的历史拜访、或询问"这个商家的拜访情况/趋势/问题"时，按以下步骤分析。

## 步骤

1. 收集该商家的历史拜访记录（日期、要点）。若信息不足，先询问补充。
2. 基于记录产出三个部分，且**只能基于记录中的事实**，不得编造：
   - **趋势**：合作/活跃度/意向的变化观察。
   - **异议**：客户表达过的顾虑或反对意见。
   - **待办**：据此应推进的下一步动作。
3. 用简洁中文分节输出，每条给出对应的记录依据。

## 注意

- 不做疾病/心理诊断，不推断受保护属性。
- 低置信度的推测要标注为"推测"，不要表述为事实。
