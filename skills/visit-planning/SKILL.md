# 拜访规划 Skill

当用户请求"制定拜访计划/拜访规划/拜访方案"时，按以下步骤产出一份结构化的销售拜访计划。

## 步骤

1. 明确本次拜访的**目标商家**与**核心目标**（如推动续约、挖掘新需求、处理异议）。
   若用户没说清，先用一句话询问补充，不要臆测。
2. 结合已知的商家背景与检索证据，产出以下四个部分：
   - **拜访目标**：1–3 条明确、可衡量的目标。
   - **议程**：有序步骤（开场 → 回顾 → 探询 → 方案 → 处理异议 → 约定下一步）。
   - **准备材料**：本次拜访需要携带/准备的资料。
   - **跟进项**：拜访后的跟进动作与时间点。
3. 用简洁中文分节输出，不要编造商家不存在的事实。

## 输出格式

参考 [templates/plan-outline.md](templates/plan-outline.md) 的分节结构。
